OFFICEFURNI - HTML/CSS PROTOTYPE

This version intentionally uses ONLY:
- HTML5
- CSS3

No PHP, MySQL, JavaScript, Bootstrap, or external libraries are required.

HOW TO RUN:
1. Extract the folder.
2. Open index.html in Google Chrome, Microsoft Edge, or another browser.
3. Navigate through Home, Products, Categories, Cart, Checkout, Orders, and Account.

IMPORTANT:
Because this is HTML/CSS only, search, cart updates, checkout submission, login, and admin/database functions are visual prototypes. They do not actually save data.

The pages and layout are based on the submitted Online Office Furniture E-Commerce System proposal.
